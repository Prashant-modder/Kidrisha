# Kidrisha'Chandra' — Numbers

Base 16. Symbols: `0`–`9`, then `A`–`F` for 10–15. 16 is the first two-symbol number.

## Cardinal Digits 0–F (0–15)

| Value | Symbol | Word |
|---|---|---|
| 0 | 0 | Nyūra |
| 1 | 1 | Īṣva |
| 2 | 2 | Dēvānī |
| 3 | 3 | Amṛṣā |
| 4 | 4 | Sōmaka |
| 5 | 5 | Raṣēvā |
| 6 | 6 | Kālindra |
| 7 | 7 | Tiṣvāra |
| 8 | 8 | Uṣṇāra |
| 9 | 9 | Vandhīra |
| 10 | A | Āndrēṣa |
| 11 | B | Sudhāmra |
| 12 | C | Nirvāṣa |
| 13 | D | Āraṇyata |
| 14 | E | Prathīra |
| 15 | F | Śōdhana |
| 16 | 10 | Daśāla |

## Ordinal

Suffix `-iṣ`:

| Ordinal | Form |
|---|---|
| 1st | **Īṣv**-iṣ |
| 2nd | **Dēvān**-iṣ |
| 3rd | **Amṛṣ**-iṣ |

## Fractions

`-amśa` suffix on the denominator's root:

| Fraction | Form |
|---|---|
| 1/2 | Dēvān-amśa |
| 1/3 | Amṛṣ-amśa |
