# Kidrisha — Core Rules

- Not a tonal language.
- Two versions of the language: **Informal** and **Formal**.

## Informal vs Formal

| Part | Informal Version | Formal Version |
|---|---|---|
| Verb | `Verb+Tense`<br>`Interjection/Mood` | `Interjection/Mood+Verb+Tense` |
| Noun | `Noun`<br>`Form`<br>`Gender`<br>`Number` | `Number+(Form, Gender)+Noun/Pronoun` |
| Pronoun | `Pronoun`: Personal / Demonstrative / Relative / Interrogative | |
| Modifiers | `Preposition`<br>`Adjective`<br>`Adverb` | |
| Word order | Object │ Verb │ Subject | Any order |
| Placement | `Noun/Pronoun, Form, Gender, Number, Adjective+Preposition` ││ `Adverb+Verb+Tense, Mood/Interjection` │ `Noun/Pronoun, Form, Gender, Number, Adjective+Preposition` | Noun/Pronoun's adjective comes after the object.<br>Preposition comes after adjective/adverb.<br>Verb's/Adjective's adverb comes after them. |

## Order of Sentence

**Informal**

```
(Noun/Pronoun + Form + Gender + Number + Adjective + Preposition)
-(Adverb + Verb + Tense + Mood/Interjection)
-(Noun/Pronoun + Form + Gender + Number + Adjective + Preposition)
```

**Formal** — if it is in OVS:

```
(Interjection/Mood + Verb + Tense)
--(Adverb)
--(Preposition)
--(Number + [Form, Gender] + Noun/Pronoun)
```

## Rules

### Showing respect

Respect mentions only the **primary relation** as `Dādi Mami`, to Dādi only.

> *Primary relation marks the relation on the table and counts the generation.*

### Direct relation

Direct relation is of the person in the subject.

> **Mother's Māmi is:** `Dadi mami`
> Dadi (Subject, direct relation) + Mami (Object, indirect relation)
>
> **Mami's mother is:** `Mami dadi`
> Mami (Subject, direct relation) + Dadi (Object, indirect relation)

### Pronouns

To apply any pronoun kind, a small prefix/suffix is added to the subject/object when mentioning it.
