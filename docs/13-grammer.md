# 3. Grammar

## Sentence Order

- **Formal:** Any order will work.
- **Informal:** OVS — *Banana eats Ram*

### Formal

**Object / Subject**

```
Adjective [Based on Gender]  -
Noun (Raw)                   +
NumberForm (Number + Form [Based on Gender])  -
Preposition
```

> **Example:** `सतोः+बालाका+भ्याम्+सह`

See [Noun Forms](04-noun-forms/00-overview.md).

**Verb**

```
Adverb  -
Verb (Raw)  +
Verb Tense (Tense + Person + Mood/Interjection)
```

> **Example:** `शीघ्रं+पठ+तु`

See [Verbs & Tenses](05-verbs-tenses.md).

### Informal

**Object / Subject**

```
Adjective  -
Noun  -
(Interjection/Mood - (Gender + Form + Tense))  -
Preposition
```

**Verb**

```
Adverb  -
Verb + Verb Tense (Tense + Person + Mood/Interjection)
```
