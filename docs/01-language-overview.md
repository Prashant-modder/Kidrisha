| Field | Value |

| Modifiers | 9 |

| Semi-Vowels | 13 |

| Numbers | [Number System](03-number-system.md) |
| Punctuation Marks | |
| Digital Font | |
| Keyboard Layout | |
| Calligraphy | |

Each glyph has one absolute sound; context-dependent readings are not used. Aspirated consonants are written as one glyph with a superscript `ʰ`, modifiers attach to vowels or the silent carrier `ʼ`, and diphthongs are written as two separate vowels.

For the complete inventory and pronunciation rules, see [Phonology](12-phonology.md).
